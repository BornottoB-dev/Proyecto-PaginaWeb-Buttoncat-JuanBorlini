# Project Rules & Guidelines

## Emojis Strictly Forbidden
- NEVER use Unicode emoji characters anywhere in the codebase (JSX, TSX, TS, CSS, HTML, string literals, comments, mock data, or UI option labels).
- Use Lucide React icons or standard non-emoji SVG/Unicode text symbols (e.g. `✓`, `✕`, `✦`) when visual indicators are required.
- Maintain this rule for all current and future user requests and feature implementations.
